# Contribuindo para Discord Ticket Bot

Obrigado por se interessar em contribuir! Aqui estão algumas diretrizes:

## Como Contribuir

1. **Fork o projeto**
2. **Crie uma branch para sua feature** (`git checkout -b feature/AmazingFeature`)
3. **Commit suas mudanças** (`git commit -m 'Add some AmazingFeature'`)
4. **Push para a branch** (`git push origin feature/AmazingFeature`)
5. **Abra um Pull Request**

## Padrões de Código

- Use Python 3.8+
- Siga o PEP 8
- Execute `black main.py` para formatar código
- Adicione testes quando possível

## Reportando Bugs

Ao reportar bugs, inclua:
- Descrição clara do problema
- Passos para reproduzir
- Comportamento esperado
- Comportamento atual
- Screenshots se relevante

## Sugestões de Features

- Descreva a feature de forma clara
- Explique por que seria útil
- Liste exemplos de como seria usada

Obrigado pela contribuição! 🚀
